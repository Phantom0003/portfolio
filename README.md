## 📖 About

Galaxy Portfolio is a responsive portfolio website that allows visitors to explore my projects, skills, experience, and achievements. It also includes an admin dashboard for managing website content.

---

## ✨ Features

- 🎨 Modern responsive UI
- 👤 About Me section
- 💼 Project showcase
- 📝 Blog management
- 📬 Contact form
- 🔒 Secure admin dashboard
- 📱 Mobile-friendly design

## 🚀 Installation

```bash
git clone [https://github.com/Phantom0003/portfolio.git]
```

1. Move the project to **xampp/htdocs**
2. Import the SQL database
3. Start Apache & MySQL
4. Visit:

```
http://localhost/portfolio
```
